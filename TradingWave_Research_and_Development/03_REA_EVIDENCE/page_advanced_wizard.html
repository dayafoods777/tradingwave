How it works

How the Advanced Wizard works

  1. [ 01 ]

    Set the entry

    Name, intraday or positional, start and end time, and entry by weekday or by days to expiry.

  2. [ 02 ]

    Add the legs

    Add each leg with its strike (ATM, or up to 20 strikes in or out of the money) and expiry. Add range breakout, re-entry, move stop-loss to cost or tranching to any leg.

  3. [ 03 ]

    Set the exits

    Profit and loss limits as a percentage of capital or an amount, a trailing stop-loss, exit on expiry or after a number of days.

  4. [ 04 ]

    Check the payoff and save

    Look at the payoff, save, then backtest it, run a parameter sweep, or deploy.

When to use it

Use the Advanced Wizard when the Option Wizard's questions are not enough but you still want a guided builder rather than writing conditions in the Strategy Builder.

Questions

Common questions

What can it trade?
F&O. Each strategy is a set of option and futures legs on one underlying.
What is a parameter sweep?
A backtest that runs the same strategy across a range of values for a setting, so you can see how sensitive it is to that setting.
What is range breakout?
A leg that enters only when the price breaks out of the range it made over a period you choose.
How is it different from the Option Wizard?
It adds entry by days to expiry, per-leg range breakout, re-entry, move stop-loss to cost and tranching, and parameter sweeps.
